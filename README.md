# BlockScript
2D editor with blocks and lines

Modes:
|- View - You cannot do with blocks & lines & points; SHIFT - Slow down, CTRL - Speed up, H - Home, ] - Hide grid.
|- Drag - You can drag blocks & points; CTRL - Snap
|- Line - In this mode you can choose 2 submode:
|  |- Build - You can create lines & points, to create line you need click LMB on block or point; P - create point
|  |- Delete - You can delete lines & points by clicking LMB
|- Block - In this mode you can choose 2 submode:
|  |- Build - You can create blocks by clicking RMB on nothing -> create -> <Block Name>, by clicking RMB on block, will open another window with parameters
|  |- Delete - Yoe can delete blocks
